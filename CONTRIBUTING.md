# Contributing

This project is open source, not open contribution. Issues are welcome; pull
requests are not accepted and will be closed.

Entry Place keeps sole copyright over this package. That keeps the ownership
position simple and leaves the option of licensing it commercially.

Open an issue for bugs (include the package version and your Next.js
version), for feature requests, or for anything the README did not answer.
Describe the problem rather than pasting an implementation: code you write
belongs to you, and copying it in without a licence agreement would muddy
the ownership above.

For a security problem, email info@entryplace.com.au instead of opening a
public issue.
